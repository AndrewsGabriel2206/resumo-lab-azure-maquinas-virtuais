# Resumo do Laboratório - Máquinas Virtuais no Microsoft Azure

## Objetivo

Neste laboratório tive contato com os conceitos fundamentais de computação em nuvem utilizando a plataforma Microsoft Azure, com foco na criação e gerenciamento de Máquinas Virtuais (VMs).

## O que aprendi

### Computação em Nuvem

Aprendi que a computação em nuvem permite utilizar recursos computacionais pela internet sem a necessidade de adquirir infraestrutura física própria.

Entre os principais benefícios estão:

* Escalabilidade
* Elasticidade
* Alta disponibilidade
* Segurança
* Gerenciabilidade
* Redução de custos

### Máquinas Virtuais

As Máquinas Virtuais permitem criar ambientes completos de sistemas operacionais hospedados na nuvem.

Durante o laboratório aprendi a:

* Criar uma Máquina Virtual no Portal Azure.
* Escolher a imagem do sistema operacional.
* Configurar tamanho da máquina virtual.
* Configurar usuário e senha de acesso.
* Configurar regras de rede e segurança.
* Conectar-se à máquina virtual após sua criação.

### Recursos Configurados

Durante a criação da VM foram definidos:

* Grupo de Recursos (Resource Group).
* Região de implantação.
* Sistema Operacional.
* Usuário administrador.
* Regras de acesso remoto.
* Configurações de armazenamento.

### Benefícios do Azure

O Microsoft Azure oferece:

* Facilidade de gerenciamento através do Portal Web.
* Criação rápida de recursos.
* Monitoramento dos serviços.
* Escalabilidade sob demanda.
* Integração com diversos serviços de nuvem.

### Conclusão

Este laboratório permitiu compreender na prática como criar e administrar máquinas virtuais no Microsoft Azure. Além disso, reforçou conceitos importantes de computação em nuvem, escalabilidade, disponibilidade e gerenciamento de recursos, conhecimentos essenciais para profissionais da área de tecnologia.
